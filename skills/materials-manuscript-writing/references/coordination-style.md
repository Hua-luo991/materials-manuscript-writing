# 章节协调与语言

## 跨章节组织

私下形成主要贡献、关键证据与位置的简短对应。让引言准备结果回答的问题，让图和方法支持相关判断，让讨论综合认识，让结论回到已经建立的贡献。

同一发现可以在多个部分出现。摘要呈现答案，引言末段说明本文工作，结果建立依据，讨论综合解释，结论提炼贡献。保持事实一致，使每次出现具有实际任务。

| 需要保持对应的对象 | 涉及位置 |
| --- | --- |
| 主要问题与答案 | 引言、结果、结论 |
| 核心贡献与表述范围 | 题目、摘要、引言末段、结论 |
| 样品与制备身份 | Methods、正文、图注、SI |
| 数值和工况 | 结果、图、图注、分析方法 |
| 模型与观测 | 解释、计算、对照、示意图 |
| 补充项目 | 主文或Methods引用、SI目录、实际内容 |

## 清楚自然的句法

使用具体主语和直接动词，减少长条件夹在主语与谓语之间。让前句引入的对象成为后句的起点。含糊的this、it或these changes有多个候选对象时重复具体名词。

对常见叙述使用form、grow、increase、decrease、remain、compare、measure等词；为准确区分保留必要术语。保持技术名称稳定，普通词按语义调整。

实验观测通常使用过去时，当前图形或模型关系可使用现在时。现有事实使用适当现在时，具体以往实验按过去时；按任务使用现在完成时。避免全稿统一成一种时态或语态。

## 压缩

先减少空泛背景、方法清单、评价词和重复解释。保留定义、比较、决定意义的条件，以及有解释价值的差异。让图展示多维数据，让正文提取主要关系。

保留已经定义的短标签。勿在每次出现时重复完整制备名称，也勿通过同义词轮换使样品或量发生漂移。

## 与用户约定的修改尺度

按本次要求完成整稿重构、章节重写、语言润色或局部收尾。局部任务保留未涉及的结构；全文任务按贡献重排有必要调整的部分。

正式稿直接报告工作和发现。将实质事实疑点置于成稿外的简短作者说明；后台完成数据和图文校核。避免因预判质疑而向正文添加反复解释或扩大任务范围。

交付前核对事实对应、科学含义和语句自然程度。Word文档按要求处理修订、批注、字体、图表及上下标。用户要求原图不改时按原要求处理。

## 在写作前后保持同一科学对象

先私下整理主要样品、关键数量和对应图号，足够支持当前任务即可。跨章节回扣时维持这些身份，避免摘要把最优器件写成全体器件水平、结论把投料量写成晶体掺杂量、图注把测点数写成样品数。

对同一结果改变的是叙述任务：引言说明研究安排，结果建立关系，讨论综合机制，结论提炼贡献。保留相同术语，不以更换技术名词制造语言变化。

方法中的定义应让读者在首次遇到结果时能够理解。主文只需短定义，完整配方和分析放Methods或SI。修改图号后同时核对主文、图注、补充入口和SI目录。

## 按编辑任务控制输出

| 作者请求 | 完成的输出 |
| --- | --- |
| 润色一个摘要 | 完整可用摘要；仅列会改变意思的缺失事实 |
| 压缩Results | 保留结果与比较，删重复、合并共用条件；必要时调整段落 |
| 整理主文与SI | 给出实际内容分配并完成相应文字与引用 |
| 修改图注 | 逐图成稿，准确对应面板、条件与统计 |
| 全文重构 | 围绕贡献组织各节，保持事实与图文对应 |

把事实问题的处理放在交付正文之外。对数字冲突先查权威记录；仍不能确定时仅指出具体冲突并完成其他独立修改。不要为了模糊一个缺项而在整段加入保留语，也不要未经要求把润色转成新的实验计划。

句子层面的改写见sentence-craft.md；数量定义和对比见quantity-comparisons.md。需要论文实例时搜索案例或索引，不在每次局部润色时加载整套文献资料。
