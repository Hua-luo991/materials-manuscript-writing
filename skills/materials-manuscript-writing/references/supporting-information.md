# 主文与补充材料

## 先按用途分配

让主文呈现主要发现、决定性比较和影响核心解释的条件。以SI展开相关细节、完整展示、额外样品、推导和验证。按内容在本文中的作用选择位置。

保持完整的实验与分析记录，避免在主文平均展开所有材料。将会改变主要判断的实际观测纳入相应论述，按它准确组织贡献。

## 选择SI形式

| 内容 | 写法 |
| --- | --- |
| 附加实验图 | 按主题或主要论证顺序排列图和完整图注 |
| Supplementary Methods | 按操作或分析顺序，明确新增步骤与变动条件 |
| Supplementary Note | 交代用途、定义量和输入、展开分析或推导、说明所得关系 |
| Supplementary Discussion | 围绕需要展开的解释组织证据 |
| 表或数据文件 | 保留样品、单位、列名、处理和必要脚注 |
| 视频 | 说明工况、时间与播放关系、尺度和标记 |

长SI设置目录与页码。小节保持局部完整，沿用主文术语。不要重复整篇引言、宏观意义或整套方法；准确引用共同程序并说明变化。

## 在主文提供有内容的入口

在相关结果或Methods处说明SI增加的信息，再引用具体图、表、Note或视频。根据任务写明完整图谱、额外批次、时间稳定性、推导或收敛分析。

主文应让读者理解主要判断，SI使所需的细节和延伸分析容易找到。避免只写更多结果见SI而省略当前结果的含义。

## 写补充图注

使图与图注可以被单独理解。定义样品、面板、关键条件、尺度、符号、数据处理和实际存在的统计。明确其与主图样品或分析的联系。

完整图谱写明范围和曲线身份；重复结果写明重复单位；映射写明区域和深度；模型检验写明参照和设置。较长解释放入对应Note，图注说明展示。

## 处理期刊差异

遵循目标期刊当前的SI、Extended Data、Source Data、编号和附件规定。未指定期刊时先形成内容分工，不把某一家期刊的字数、名称或文件格式当作普适规则。
