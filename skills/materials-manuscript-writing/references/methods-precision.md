# 方法与科学措辞

## 写简短且可执行的程序

以溶液、样品、晶体、器件或数据为主语，按操作顺序描述。保留操作对象、量、关键条件、结束或判定程序及后处理。

将共同流程定义一次，再列出各组变动的配比、温度、时间或其他变量。采用文献方法时写明实际修改。新增核心步骤给予足够描述。

以过去时记录已完成的操作。被动结构自然时优先使用；计算或分析步骤以清楚为准。仪器型号与实际测量条件、几何和数据处理共同构成方法。

## 按模块安排必要细节

| 模块 | 相关信息 |
| --- | --- |
| 溶液与前驱体 | 物种、预处理、加入量、摩尔比、溶剂、浓度定义与比例分母 |
| 生长程序 | 容器和液量、温度路径、时间、籽晶或成核条件、搅拌与供给、取晶 |
| 生长测量 | 记录量、采样间隔、长度体积或质量定义、温度、判据 |
| 结构与缺陷 | 晶面、区域、取样、分辨率、分析范围和统计口径 |
| 器件制备 | 厚度与取向、表面处理、电极和面积、沉积与封装 |
| 测试与分析 | 几何、施加条件、环境、源与标定、读取、指标定义和计算 |
| 计算与模型 | 结构组成、理论或势、数值设置、采样收敛、边界和参数来源 |

使用已有记录，不凭经验补入未提供的步骤。把确实影响当前句子意义的缺失事实放在成稿外简短说明。

## 固定样品与计量定义

首次说明材料、处理对象、添加量基准和必要条件，随后统一简称。

| 实验定义 | 精确写法 |
| --- | --- |
| EtOH按原始溶剂体积加入 | 2 mL of EtOH per 100 mL of the original solvent |
| EtOH按原始溶剂质量加入 | 2 g of EtOH per 100 g of the original solvent |
| EtOH占最终溶液总质量 | 定义该分母后使用2 wt% EtOH in the precursor solution |
| 金属名义投料比 | 指定基准元素和物质的量之比 |
| 晶体实测含量 | 指定组成测量方法和质量或原子含量基准 |

根据原始记录选择定义，禁止把体积添加比改为质量分数或最终混合液比例。在含EtOH生长液中长成的晶体按生长条件命名，实测残留或掺入含量另行报告。

## 使物理量保持各自含义

分别命名PL衰减、拟合分量和物理寿命；μ与μτ；像素间距与空间分辨率；晶相组成与结构完整性；体相平均与局部表面量。

将每项数值与对应样品、工况和取值类型相连。区分同材料、同批、同晶体、同器件和同工况；区分最优值、代表值、均值与分布。用局部条件完成精确表达，无需在句末惯例性自我否定。

对带符号信号明确代数变化或绝对幅度，尤其负电流、负峰、能级或势阱。按实际数据保留量纲和上下标。

## 记录数据处理

交代背景扣除、归一化、积分范围、拟合区间、峰型、方程及参数来源。按实际操作定义饱和、成核和稳定等判据。用记录过的时间、速率或状态说明sufficient、slow、stable等词的含义。
