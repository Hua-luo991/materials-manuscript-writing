# 图与图注

## 设计图的任务

确定每张图服务的关键认识，再排列面板。装置说明控制方式，时间序列显示动态过程，映射展示空间分布，比较或拟合图显示对应关系。

使正文中的判断与实际面板对应。让图号靠近所支持的结果；复杂图可先介绍整体布局，简单趋势直接以样品或物理量作主语。

## 写图注

用简短标题界定全图，按面板顺序说明对象，再交代共享条件与数据定义。标题采用描述性或结果式形式时，结合目标期刊风格和实际证据选择。

按图形实际需要定义：

- 样品、处理状态、组成、区域、晶面和器件身份。
- 面板、曲线、点、颜色、阴影、插图及比例尺。
- 决定图义的温度、偏压、激发、时间点或其他变量。
- 归一化、纵向偏移、积分或背景处理。
- 实测点、拟合、理论预测、连接线和视觉引导线。
- 存在的中心值、误差条、样本量与适用统计说明。

保持图的独立可读性，将完整实验步骤留在Methods。图注重点说明展示，较长解释留在正文。单次测量或示意图无需编造重复、统计或误差条。

## 精确说明统计层级

区分独立晶体、同晶体测点、独立器件、重复扫描、独立合成批次及粒子数。按实际单位定义n、每个点、中心值和误差。

当一个点表示一块晶体内多个测点的均值，而误差条为这些测点的标准差时，可写：Each point shows the mean for one crystal; error bars indicate the standard deviation across the positions measured within that crystal.

只在实际统计结构相同时使用该示例。将均值、中位数、标准差或置信区间写成真实采用的定义。

## 写补充图注

同样定义样品、面板、关键条件与数据处理。明确额外批次与主图的关系；为映射交代区域和深度，为时间序列交代起点和间隔，为验证图交代参照数据和设置。

引用共同方法时保留本图对象和变动条件，避免仅用same as Fig. 2让读者恢复全部信息。完整XRD展示说明样品、顺序、参照及偏移；形貌与粒径统计保持对应。

视频说明对象、工况、真实时间、播放或加速方式、尺度及标记。按目标期刊处理Extended Data、SI、图号和文件形式。

## 先分清正文、图面与图注的任务

正文回答这组结果建立了什么关系。图面让比较可见。图注提供独立阅读所需的对象、条件、符号和数据定义。三者可以共享关键事实，但不必逐句重复。

| 图形任务 | 优先安排的面板和说明 |
| --- | --- |
| 生长过程 | 装置或控制图、时间轨迹、关键时点、最终材料；定义时间零点与观测方向 |
| 结构到功能 | 结构身份或局部构型、相应信号、功能比较；保留同一样品标签 |
| 空间均一性 | 位置图、映射、分布或统计；定义区域、深度与测点层级 |
| 物理模型 | 观测、模型结构、预测关系；区分实验点、计算线及参照零点 |
| 器件性能 | 构型、工作曲线、比较或实际功能；注明有效面积、厚度及工况 |

对时序图注明处理开始、曝光或测量开始的参照。对方位图说明样品轴、基底、晶面法向和探测方向。倒空间q以逆长度表示，直接空间尺寸以长度表示。

## 处理多面板与插图

共享条件写一次；局部不同条件紧邻相应面板。逐项对应不同面板的比例尺，避免多种尺寸只有一个不明指向的scale bar。图中颜色已有两个含义时重新安排图例，不依赖读者猜测。

分布图注明取样对象和计数方式；代表像注明代表的材料或处理。对峰谱注明归一化基准、纵向错位和背景处理。连接线、拟合线、计算曲线和guide to the eye采用各自准确名称。直线用于引导视线时不改写成拟合结果。

均值、标准差、拟合参数误差和置信区间各有来源。图注按实际定义说明。相同位置的多次扫描、同一晶体的多个位置和独立晶体之间的统计层级须保留。n未知时先完成可确定的图注，将具体缺项留在成稿外。

## 图注的压缩与补充图的扩展

从全图任务进入面板说明，将图形共享的定义集中到末尾。不能仅为缩短图注删去会改变读图含义的样品状态或测试条件。补图可以更详细地说明完整系列、取样和处理，但长推导或机制说明优先独立成Note。

SI中的方法示意图可以承担文字难以压缩的几何定义，如四探针电极间距、样品宽度和厚度。正文Methods保留计算关系并指向该图；不必在每个性能段重复几何设置。

参考案例：C01–C06、C08–C11、C14–C18。
