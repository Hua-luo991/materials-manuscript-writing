# 数量定义与比较

## 先给数量一个完整身份

每个关键数值与对象、条件、定义和取值类型相连。共同条件已在邻近位置明确时可以省略，跨章节或跨器件复用数值时保留足够身份。

| 容易混写的量 | 选择准确表达 |
| --- | --- |
| 加入量、溶液组成、固体组成 | 相对原溶剂加入量；最终溶液质量或体积分数；产物实测含量 |
| 母液浓度与名义化学式 | 指定浓度基准和前驱体比例，实测相或元素组成另述 |
| 晶体、晶粒、相干衍射域 | 对应宏观单晶、显微形貌晶粒和衍射模型中的相干域 |
| PL峰宽与XRC峰宽 | 分别说明谱线或反射、坐标、单位和分析 |
| 衰减时间与寿命 | 说明拟合模型、分量、平均方式、激发和载流子提取环境 |
| 迁移率、扩散系数与μτ | 给提取方法、载流子类型和计算关系，分别使用正确单位 |
| 空间分辨率、定位精度与像素间距 | 分别说明辨别结构、估计位置和采样尺寸的定义 |
| 电流、响应度、灵敏度与光产额 | 指定入射量、剂量或能量基准及面积、体积归一化 |
| 离子与电子运输 | 指定驱动力、测量构型和所提取的分量 |
| 实际厚度与有效厚度 | 区分显微测得几何厚度与模型使用的响应厚度 |

准确命名不要求每段都解释定义。首次必要位置定义，随后使用稳定短名。

## 百分数保留分母

相对原溶剂加入2 mL EtOH至100 mL原溶剂，应直接保留这个比例；不要改成最终溶液2 vol%。最终混合体积分数还取决于混合体积定义。按原溶剂质量加入2 g至100 g，也不同于最终混合物2 wt%。

投料中的金属摩尔比例可写n(M)/n(Pb)，替位比例可写化学式中的x，原子百分数要明确所含元素集合。标签如M-5可以方便比较，但需先定义5所代表的量。

商业原液中的15 wt%固含量、工作液中的稀释浓度、最终膜中的含量分开。HBr等试剂的溶液浓度与痕量金属纯度属于不同指标。

## 让比较对象同量同义

同一条件下的变化可直接报告前后值、差值或比值。不同构型或工况下的性能保持各自身份，选择与本研究问题有关的比较。按面积、催化剂质量、活性金属质量和位点数归一化各自回答不同问题。

| 比较类型 | 应保留的最短条件 |
| --- | --- |
| 单晶生长 | 生长方向、时间区间、温度路径、批式或持续供给 |
| 结构均一性 | 单块晶体的位置、不同晶体或不同批次；范围与分布 |
| 电学或探测 | 厚度或电极距离、偏压或电场、源谱和剂量率、面积定义 |
| 发光和衰减 | 材料状态、基底或提取层、激发条件与归一化 |
| 机械和电导 | 干态或湿态、介质、应变、测试方向 |
| 催化 | 电解液、参考电极、归一化分母、校正与反应条件 |

最优值用于展示达到的水平，均值和分布用于描述样品总体。一个晶体五个位置的范围可直接呈现空间均一性；五个位置保持其实际取样含义。

对带符号量，使用became more negative、shifted toward higher energy或increased in magnitude等具体方向。百分比增加和百分点变化分别计算；倍数的参照值在邻近句子中明确。

参考案例：C02–C06、C08–C18；实际数字和公式使用前回到相应稿件或原文。
